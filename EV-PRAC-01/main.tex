\section*{1. Conceptos aplicados al caso}
\textbf{A. Explique con sus palabras qué es un requisito según ISO/IEC/IEEE 29148 y decida si E4 y E12 son requisitos del producto FRIOVAC. Justifique en una o dos líneas.}

\textbf{Respuesta:} Un requisito es una necesidad, capacidad o condición que debe cumplir el sistema para satisfacer a un interesado.

\textbf{B. Explique qué describe la especificación de requisitos de los interesados, la especificación de requisitos del sistema y la especificación de requisitos de software en este proyecto.}

\textbf{Respuesta:} La SRS permite saber qué necesitan la directora, la coordinadora y la responsable de vacunatorios, ya que define cómo debe funcionar FRIOVAC con sensores, comunicación, plataforma web y aplicación móvil.
